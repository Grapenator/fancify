# CSC 193A Web Programming Assignment

## Assignment 5 - Fun with JavaScript  

---

## ✅ Description  
Test out your JavaScript by writing a page where the user can type text into a box, and by clicking on UI controls, the text will get styling. The HTML page `index.html` (previously `fancifymytext.html`) contains a basic HTML shell and page header.

You will write a JavaScript file `fancifymytext.js` that will manipulate the text.

---

## ✍️ Tasks

### 🧩 HTML Structure
- Add a large multi-line text box (4 rows x 30 columns)
- Wrap it in a `<fieldset>` with the label "Text"
- Add another `<fieldset>` labeled "Fancify" with:
  - A button labeled **Bigger!**
  - Two radio buttons: "FancyShmancy" and "BoringBetty"

### 💻 JavaScript Functions
- Add a `Hello, world!` alert on button click using a function
- Use `onclick` and `onchange` handlers
- Style the text area:
  - Bigger: changes font size to 24pt
  - FancyShmancy: bold, blue, underlined
  - BoringBetty: resets styles to normal

### 🐄 Moo Button
- Uppercases the text
- Adds `-Moo` to the last word of each sentence
